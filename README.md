# تطبيق تقييم الحروف العربية 🎓

تطبيق ويب تفاعلي لتقييم وتشخيص مستوى إتقان الطلاب للحروف العربية من خلال التعرف الصوتي.

## 📋 المزايا الرئيسية

✅ **تقييم شامل** - تقييم جميع 28 حرفًا من الحروف العربية
✅ **تعرف صوتي حقيقي** - باستخدام Web Speech API
✅ **نتائج تفصيلية** - نتيجة لكل حرف بشكل مستقل
✅ **تصميم صديق للأطفال** - واجهة بسيطة وواضحة وجذابة
✅ **عربي بالكامل** - لا توجد نصوص إنجليزية في الواجهة
✅ **RTL** - دعم كامل للنصوص العربية من اليمين إلى اليسار
✅ **متجاوب** - يعمل على جميع أحجام الشاشات
✅ **تحفظ النتائج** - حفظ محلي للنتائج في localStorage
✅ **تحميل التقارير** - تحميل النتائج كملف JSON

## 🎯 آلية عمل الاختبار

### الخطوة 1: الترحيب
- إدخال اسم الطالب
- الضغط على زر "ابدأ الاختبار"

### الخطوة 2: الاختبار
- عرض حرف واحد في المركز
- الطالب ينطق اسم الحرف
- التطبيق يسجل ويحلل الإجابة
- انتقال تلقائي للحرف التالي

### الخطوة 3: النتائج
- عرض نتيجة كل حرف
- إحصائيات عامة (عدد ونسبة)
- قائمة الحروف التي تحتاج تدريب
- خيار تحميل التقرير

## 🛠️ التقنيات المستخدمة

- **HTML5** - البنية الأساسية
- **CSS3** - التصميم والتأثيرات
- **JavaScript (Vanilla)** - المنطق والتفاعل
- **Web Speech API** - التعرف الصوتي
- **MediaRecorder API** - تسجيل الصوت
- **localStorage** - حفظ النتائج

## 🚀 كيفية الاستخدام

### 1. الحصول على نسخة من المشروع
```bash
git clone https://github.com/alluhaybi22-byte/arabic-letters-assessment.git
cd arabic-letters-assessment
```

### 2. تشغيل التطبيق
- فتح ملف `index.html` في متصفح حديث
- أو استخدام خادم محلي:
```bash
python -m http.server 8000
```
ثم الذهاب إلى `http://localhost:8000`

### 3. استخدام الاختبار
1. أدخل اسم الطالب
2. اضغط "ابدأ الاختبار"
3. انطق اسم كل حرف عند ظهوره
4. انتقل للحرف التالي
5. اعرض النتائج التفصيلية في النهاية

## 📊 تفاصيل النتائج

### شاشة النتائج تعرض:

**1. الإحصائيات العامة:**
- عدد الحروف المتقنة
- عدد الحروف غير المتقنة
- نسبة الإتقان المئوية

**2. نتائج الحروف التفصيلية:**
- كل حرف مع حالته (✓ متقن أو ✗ غير متقن)
- ألوان مميزة للحروف الصحيحة والخاطئة

**3. الحروف التي تحتاج تدريب:**
- قائمة واضحة بالحروف غير المتقنة
- تساعد المعلم في التركيز على نقاط الضعف

## 🔧 الإعدادات

في ملف `data.js` يمكن تخصيص الإعدادات:

```javascript
const CONFIG = {
    totalLetters: 28,           // عدد الحروف الكلي
    recordingTimeout: 5000,     // مدة التسجيل (ميلي ثانية)
    silenceTimeout: 1500,       // انتظار الصمت (ميلي ثانية)
    confidenceThreshold: 0.6,   // حد أدنى للثقة
    language: 'ar-SA'           // لغة التعرف الصوتي
};
```

## 🚨 استكشاف الأخطاء

### المشكلة: لا يعمل التعرف الصوتي
**الحل:**
- تأكد من استخدام متصفح مدعوم
- تحقق من إذن الميكروفون
- تأكد من اتصالك بالإنترنت

### المشكلة: النتائج لم تُحفظ
**الحل:**
- تأكد من عدم حذف بيانات المتصفح
- تحقق من localStorage في أدوات المطور

### المشكلة: الواجهة تظهر بشكل غير صحيح
**الحل:**
- حدث المتصفح إلى الإصدار الأخير
- امسح ذاكرة التخزين المؤقت (Cache)
- جرب متصفح آخر

## 📝 ملاحظات مهمة

1. **التعرف الصوتي**: قد تحتاج لإعادة المحاولة إذا كان هناك ضوضاء محيطة
2. **الحروف البديلة**: التطبيق يقبل عدة نطقات لنفس الحرف (مثل "الف" و"ألف")
3. **المطابقة الضبابية**: التطبيق يستخدم خوارزمية مطابقة ذكية تقبل الأخطاء الطفيفة
4. **التخطي**: يمكن للطالب تخطي حرف وسيتم اعتباره غير متقن
