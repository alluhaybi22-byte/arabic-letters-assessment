# Arabic Letters Windows App

نسخة جديدة منظمة من تطبيق تقييم نطق الحروف العربية، بواجهة عربية RTL مستوحاة من Windows 11.

## ما يتضمنه

- تدريب على الحروف العربية الـ28
- تقييم صوتي عند توفر Speech Recognition، مع إدخال نصي بديل
- تطبيع عربي للتشكيل والهمزات والتطويل والمسافات
- نتائج فورية، ملخص آخر جلسة، والحروف التي تحتاج إلى مراجعة
- سجل جلسات محفوظ محليًا في المتصفح
- إعدادات المظهر وتقليل الحركة ومسح البيانات المحلية

## التشغيل

	em pn install
	em pn dev

ثم افتح الرابط الذي يظهره Vite. لا يحتاج هذا الإصدار إلى خادم أو قاعدة بيانات؛ البيانات المحلية تبقى داخل المتصفح.
